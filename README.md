# otool (v2.0)

> 🚀 极速、轻量级、功能全面的纯 Go 原生桌面开发与日常运维工具箱。
> 基于现代原生 GPU 硬件加速渲染（Metal / Direct3D 11 / OpenGL），彻底告别 Webview，零 Cgo 依赖，跨平台秒级启动，常驻内存仅 ~15MB！

*(注：原 Wails 架构的历史代码已永久归档至 [v1-legacy 分支](../../tree/v1-legacy) 与 [v0.1.4-legacy 标签](../../releases/tag/v0.1.4-legacy))*

---

## 🌟 为什么从 Wails 重构为纯 Go 原生架构？

原版 `otool` 基于 Wails (Webview) 构建，虽然开发便利，但浏览器内核会带来：
- **内存开销大**：空闲时常驻 100MB ~ 250MB 内存；
- **冷启动慢**：需要初始化浏览器引擎、加载前端 JS/CSS 运行时；
- **前后端 IPC 序列化损耗**：大文件、批量图片处理等高频交互存在瓶颈。

**v2.0 纯 Go 原生架构优势**：
- **纯 Go、无 cgo**：单二进制文件分发，跨平台一键编译，无需繁琐的 C 编译器环境。
- **原生 GPU 硬件加速渲染**：界面帧率丝滑稳定，支持任意缩放与视网膜高分屏。
- **内存占用暴降 90%**：常驻内存从百兆级降至 **~15MB - 30MB**。
- **毫秒级冷启动**：即点即开，告别白屏与加载等待。

## 🛠️ 核心功能全景

### 1. 文本编解码与安全哈希 (Text)
- **对称加解密**：AES-256 (OpenSSL 兼容格式，支持 Secret Key 密文掩码切换)。
- **常见编解码**：Base64、URL 编码、Hex、Octal、Unicode、UTF-16。
- **安全哈希算法**：MD5、SHA-1、SHA-224、SHA-256、SHA-384、SHA-512、SHA-512/224、SHA-512/256。
- **HMAC 密钥签名**：支持对所有哈希算法启用 HMAC 密钥签名。
- **极速响应与交互**：左右对开紧凑布局，输入即算，字数实时统计，一键回填与复制。

### 2. 文件安全加解密与哈希 (File)
- **大文件加解密**：
  - AES-256 流式安全文件加密/解密。
  - 原生文件选择与全屏拖拽支持。
  - 加密防误操作二次确认。
  - 实时流式进度反馈 (0% ~ 100%)。
- **文件完整性校验**：极速计算大文件的 MD5、SHA-1/256/512 等校验和。

### 3. 全进制任意大数转换 (Base Conversion)
- **任意进制自由转换**：支持 2 进制到 36 进制之间任意相互转换。
- **高精度大数运算**：基于 `math/big` 引擎，彻底杜绝 64 位整型溢出。
- **实时响应校验**：输入字符合规性实时检测，非法字符智能高亮预警。

### 4. 现代二维码工具箱 (QR Code)
- **工业级高容错解码**：
  - 全面升级为纯 Go 引擎 `makiuchi-d/gozxing`（Google ZXing 纯 Go 移植版）；
  - 支持复杂背景、倾斜自适应、拍照模糊、暗光以及反色（黑底白码）秒级识别；
  - 支持拖拽/点击选择二维码图片。
- **现代美化与多格式生成**：
  - **3 种现代视觉样式**：经典方块 (Square)、精致圆点 (Dots，保持标准定位角保障扫码)、圆角流动 (Rounded)；
  - **7 款高对比度安全主题色**：曜石黑、商务蓝、深邃青、森林绿、典雅紫、中国红、极简炭，并支持自定义 Hex；
  - **中心 Logo 智能挂载**：支持直接拖拽/选择 Logo 图标，自适应等比缩放防遮盖，**自动锁定最高 H(30%) 纠错等级**并开启 SafeZone 安全隔离带，确保各大主流扫码器 100% 稳定识别；
  - **全格式矢量导出**：支持高清 PNG、JPEG 以及**无损 SVG 矢量图**导出；
  - 桌面端高质量实时渲染预览。

### 5. 图像处理与文件夹批量转换 (Image)
- **单图精细处理与可视化裁剪**：
  - 格式互转（JPG / PNG / WebP / AVIF / GIF / BMP / TIFF）；
  - 多种缩放模式（原尺寸、固定宽/高/宽高、最大限制、百分比）；
  - **可视化裁剪弹窗**：支持 1:1、4:3、16:9 比例预设、居中 80%、九宫格参考线与像素级微调。
- **文件夹全量批量递归转换**：
  - 扫描整个目录（支持递归子目录）；
  - **另存新目录**（完美镜像保持原目录树结构，跳过同格式免转码直通复制）；
  - **直接原地替换**（严格跳过同格式，带防误触红色风险提示弹窗与二次确认）；
  - 严格自覆盖拦截校验与尺寸隔离保护。

## 📦 运行与构建

### 运行与开发
```bash
go run .
```

### 编译可执行文件
```bash
# 默认构建
go build -o otool .

# 优化体积（去除调试符号表）
go build -ldflags "-s -w" -o otool .
```

### 跨平台编译 (Pure Go，无需配置任何交叉编译 CGO 环境)
```bash
# macOS ARM64 (Apple Silicon)
GOOS=darwin GOARCH=arm64 go build -ldflags "-s -w" -o otool-darwin-arm64 .

# macOS Intel
GOOS=darwin GOARCH=amd64 go build -ldflags "-s -w" -o otool-darwin-amd64 .

# Windows 64-bit
GOOS=windows GOARCH=amd64 go build -ldflags "-s -w -H windowsgui" -o otool-windows-amd64.exe .

# Linux 64-bit
GOOS=linux GOARCH=amd64 go build -ldflags "-s -w" -o otool-linux-amd64 .
```

### 执行单元测试与数据竞态检查
```bash
go test -count=1 -race -v ./...
```
