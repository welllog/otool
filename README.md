# otool (v0.3.0)

> 🚀 极速、轻量级、功能全面的纯 Go 原生桌面开发与日常运维工具箱。
> 基于现代原生 GPU 硬件加速渲染（Metal / Direct3D 11 / OpenGL），零 Cgo 依赖，跨平台秒级启动，资源占用轻量稳定。

*(注：当前发布版本为 **v0.3.0**，属 v2 纯 Go 原生架构系列；v1（Wails 架构）的历史代码已归档至 [v1-legacy 分支](../../tree/v1-legacy) 与 [v0.1.4-legacy 标签](../../releases/tag/v0.1.4-legacy))*

## 🌟 架构演进与技术特性

`otool` 早期版本基于 Wails 构建，借助优秀的 Web 生态快速完成了功能验证。随着工具箱对大文件流式安全加解密、高并发图像处理等本地计算需求的加深，v2.0 探索并转向了**纯 Go 原生桌面架构**，进一步追求极致的运行效率与简洁的工程形态。

**纯 Go 原生架构优势**：
- **纯 Go、无 cgo**：单二进制文件分发，跨平台一键编译，无需配置外部 C 编译器环境。
- **原生 GPU 硬件加速**：基于底层图形 API（Metal / Direct3D 11 / OpenGL）直出渲染，视网膜高分屏下自适应缩放与丝滑动画体验。
- **轻量资源占用**：摆脱额外解释层与独立运行时开销，常驻内存与系统负载保持轻量稳定。
- **零 IPC 损耗**：UI 交互与底层加解密、图像批处理引擎运行在同一内存空间内，消除大数据量跨进程序列化成本。
- **即开即用**：毫秒级冷启动，启动即进入可用状态。

## 🛠️ 核心功能全景

### 1. 文本编解码与安全哈希 (Text)
- **对称加解密**：AES-256 (OpenSSL 兼容格式，支持 Secret Key 密文掩码切换)。
- **常见编解码**：Base64、URL 编码、Hex、Octal、Unicode、UTF-16。
- **安全哈希算法**：MD5、SHA-1、SHA-224、SHA-256、SHA-384、SHA-512、SHA-512/224、SHA-512/256。
- **HMAC 密钥签名**：支持对所有哈希算法启用 HMAC 密钥签名。
- **极速响应与交互**：左右对开紧凑布局，输入即算，字数实时统计，一键回填与复制。

### 2. 文件安全加解密与哈希 (File)
- **大文件加解密**：
  - AES-256 流式安全文件加密/解密。
  - 原生文件选择与全屏拖拽支持。
  - 加密防误操作二次确认。
  - 实时流式进度反馈 (0% ~ 100%)。
- **文件完整性校验**：极速计算大文件的 MD5、SHA-1/256/512 等校验和。

### 3. 全进制任意大数转换 (Base Conversion)
- **任意进制自由转换**：支持 2 进制到 36 进制之间任意相互转换。
- **高精度大数运算**：基于 `math/big` 引擎，彻底杜绝 64 位整型溢出。
- **实时响应校验**：输入字符合规性实时检测，非法字符智能高亮预警。

### 4. 现代二维码工具箱 (QR Code)
- **工业级高容错解码**：
  - 全面升级为纯 Go 引擎 `makiuchi-d/gozxing`（Google ZXing 纯 Go 移植版）；
  - 支持复杂背景、倾斜自适应、拍照模糊、暗光以及反色（黑底白码）秒级识别；
  - 支持拖拽/点击选择二维码图片。
- **现代美化与多格式生成**：
  - **3 种现代视觉样式**：经典方块 (Square)、精致圆点 (Dots，保持标准定位角保障扫码)、圆角流动 (Rounded)；
  - **7 款高对比度安全主题色**：曜石黑、商务蓝、深邃青、森林绿、典雅紫、中国红、极简炭，并支持自定义 Hex；
  - **中心 Logo 智能挂载**：支持直接拖拽/选择 Logo 图标，自适应等比缩放防遮盖，**自动锁定最高 H(30%) 纠错等级**并开启 SafeZone 安全隔离带，确保各大主流扫码器 100% 稳定识别；
  - **全格式矢量导出**：支持高清 PNG、JPEG 以及**无损 SVG 矢量图**导出；
  - 桌面端高质量实时渲染预览。

### 5. 图像处理与文件夹批量转换 (Image)
- **单图精细处理与可视化裁剪**：
  - 格式互转（JPG / PNG / WebP / AVIF / GIF / BMP / TIFF / HEIC·HEIF / JPEG XL / ICO / ICNS），源格式与目标格式不必对称；
  - **HEIC/HEIF（iPhone 默认拍照格式）与 JPEG XL 双向转换**：纯 Go 编解码器（`gen2brain/h265`、`gen2brain/jxl`，无 cgo），支持质量调节与无损模式，保留透明通道，HEIC 解码自动应用 irot/imir 旋转；
  - **ICO（Windows 图标 / favicon）与 ICNS（macOS 应用图标）输出**：自动写入 16–256 / 16–1024 全部标准尺寸（不超过原图边长），非正方形原图居中裁剪为正方形（`jackmordaunt/icns`，纯 Go）；
  - **GIF 动图保真**：GIF 转 GIF 自动保留动画，支持 1/2 ~ 1/5 多档抽帧瘦身与 2–256 色调色板调节，可选「在前一帧上绘制」保持画面连贯；
  - **格式说明卡片**：切换目标格式即展示该格式的压缩率、兼容性与适用场景说明，并附画质基准建议（如「质量 95 ≈ 存档级」），无需查阅外部文档即可选型；
  - 多种缩放模式（原尺寸、固定宽/高/宽高、最大限制、百分比）；
  - **可视化裁剪弹窗**：支持 1:1、4:3、16:9 比例预设、居中 80%、九宫格参考线与像素级微调。
- **文件夹全量批量递归转换**：
  - 扫描整个目录（支持递归子目录）；
  - **另存新目录**（完美镜像保持原目录树结构，跳过同格式免转码直通复制）；
  - **直接原地替换**（严格跳过同格式，带防误触红色风险提示弹窗与二次确认）；
  - 严格自覆盖拦截校验与尺寸隔离保护。

### 6. 照片去重与相似识别 (Photo Dedup)
- **多后端统一存储抽象**：
  - 支持**本地磁盘**与 **WebDAV 远程网盘**（群晖 NAS、Nextcloud、Alist 等）；
  - 存储配置自动安全持久化（存放在 `~/.otool/storage_profiles.json`，密码经本地 AES-GCM 安全加密，密钥存放于 `~/.otool/secret.key`；迁移配置时需一并迁移密钥文件，界面直观展示配置位置并支持一键打开）；
  - **前置金丝雀权限探针**：在扫描前自动探测远程写入与删除权限，防止无权限误操作。
- **先进去重与相似识别算法**：
  - **完全精确去重**：三级过滤流水线（大小筛选 ➔ 头部/中间/尾部分块采样哈希 ➔ xxHash 全量校验）；
  - **智能相似/连拍识别**：集成纯 Go `pHash` (DCT 感知哈希) 与 `dHash` (梯度差异哈希)，支持严格/标准/宽松三档灵敏度；
  - **BK-Tree 度量空间树 + 完全链接聚类**：$O(N \log N)$ 极速成组，彻底告别海量照片 $O(N^2)$ 暴力比对卡顿；
  - **手抖模糊检测与画质综合打分**：基于 3x3 拉普拉斯卷积算子自动检测边缘模糊手抖废片，结合分辨率、EXIF 完整度、文件体积智能评选 **`👑 推荐保留 (最佳)`**。
- **直观易用的交互与安全清理**：
  - 卡片式并排对比陈列相似图片，清晰标注分辨率、体积、锐度得分差异；
  - **一键应用推荐保留**、反选、自定义勾选；
  - **分页复核与分批清理**：结果分组分页展开，超大相册（上千组重复）依然流畅；清理确认弹窗支持「仅清理已展开审阅的分组」逐批复核，也可显式授权按推荐一并清理全部分组，无需强制展开全部结果；
  - **两级安全清理机制**：默认安全移至系统废纸篓（或远程 `.otool_trash` 隔离目录），支持彻底删除二次确认；
  - **智能缓存**：缩略图按 LRU/TTL 独立淘汰，昂贵计算出的指纹按条数保留，不因缩略图清理而丢失；相似模式只为实际进入重复组的照片按需生成预览；相似模式聚类后补算的全量内容哈希也会回写指纹缓存，二次扫描无需重新读取重复组照片（WebDAV 远程源尤为明显）；
  - **格式边界**：JPEG/PNG/WebP/AVIF/GIF/BMP/TIFF 支持相似识别；HEIC/HEIF/RAW/DNG/CR2/NEF/ARW 支持字节级精确去重，相似模式会明确计入“已跳过”，不会静默漏图；
  - **可控的缓存管理**：页面展示缩略图/指纹缓存占用与数量，支持查看缓存目录、手动清理过期/超额缓存，以及带确认弹窗的一键清空（不会影响原图）。

## 📦 运行与构建

> 环境要求：Go 1.27.3+（纯 Go 实现，零 CGO，无需任何 C 编译器环境）。

### 运行与开发
```bash
go run .
```

### 编译可执行文件
```bash
# 默认构建
go build -o otool .

# 优化体积（去除调试符号表）
go build -ldflags "-s -w" -o otool .
```

### 一键打包发行（Makefile / scripts/build.sh，产物输出至 `bin/`）
```bash
make app      # 构建 macOS otool.app：自动嵌入图标 (build/icon.icns) 与 Info.plist，并施加 ad-hoc 签名
make windows  # 构建 Windows otool.exe：自动链接 .syso 图标资源，生成带图标的 GUI 可执行文件
make all      # 同时构建 macOS 与 Windows 产物
make clean    # 清理 bin/ 目录
```

### 跨平台编译 (Pure Go，无需配置任何交叉编译 CGO 环境)
```bash
# macOS ARM64 (Apple Silicon)
GOOS=darwin GOARCH=arm64 go build -ldflags "-s -w" -o otool-darwin-arm64 .

# macOS Intel
GOOS=darwin GOARCH=amd64 go build -ldflags "-s -w" -o otool-darwin-amd64 .

# Windows 64-bit
GOOS=windows GOARCH=amd64 go build -ldflags "-s -w -H windowsgui" -o otool-windows-amd64.exe .

# Linux 64-bit
GOOS=linux GOARCH=amd64 go build -ldflags "-s -w" -o otool-linux-amd64 .
```

### 执行单元测试与数据竞态检查
```bash
go test -count=1 -race -v ./...   # 亦可 make test
```
